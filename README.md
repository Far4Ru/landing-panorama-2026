# Panorama Menu

A responsive content hub with a looping 3D carousel, resource cards, and a contact section.

[Live demo](https://far4ru.github.io/landing-panorama-2026/)

## Features

- Browse collections using navigation, keyboard arrows, or swipes.
- Open resources full-screen and return to the same place.
- Keep the globe and navigation synchronized with the carousel.
- Customize sections, cards, and links in [src/data.ts](src/data.ts).

Demo: 7 sections and 20 cards. Links and contact details are placeholders.

## Design

`Holographic` `3D carousel` `Transparent panels` `Dark navy` `Cyan glow` `Responsive`
